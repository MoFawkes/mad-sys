# AQI Clock v0.16.2

## Fixed Zuhr

In **Administration → Prayer times → Fixed prayer times**, set Zuhr to start at **12:30** with a length of **20 minutes**, choose the effective date, and save. The editor displays Salah at **12:37**. Automatic timetables that adjust for prayer reserve the break from **12:30 to 12:50**. The Friday Jumu'ah setting takes precedence on Fridays.

## Windows reminders

- Recurring **After every lesson** reminders now cover class-specific timetables as well as the organisation-wide timetable.
- Windows submits notifications in the background and skips stale clock ticks during a slow notification submission.

## Install and update

Existing Windows installations receive v0.16.2 through the stable updater. The Setup executable and portable ZIP are attached to this release. Android remains on v0.16.0.
